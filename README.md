# Bruer Family Photographs

A static SvelteKit + Tailwind site of Bob Bruer's family photo collection: each photo
with its caption shown beside it (not burned into the image), an AI-enhanced version,
and research notes, including places where captions conflict.

## The site

```
npm install
npm run dev       # http://localhost:5173
npm run build     # static site in build/
```

Content lives in `src/lib/data/`:

- `captions.json`: photo id → caption text. Hand-editable; fix typos or OCR slips here.
- `observations.json`: research notes. `kind` is `conflict` ("Doesn't add up") or
  `pattern`. Each note lists the photo ids it belongs to and shows under those photos and
  on the Notes page.
- `tags.json`: photo id → `year` (`yearIsGuess` when estimated), `families`, `topics`. Guessed
  from captions by `pipeline/5_tag.py`; hand-editable, and hand fixes survive re-runs.
- `photos.json`: generated by the pipeline (sizes, whether an enhanced version exists).

Images are in `static/photos/<id>/` as `original.webp`, `enhanced.webp` and `thumb.webp`.

Deploy: import the GitHub repo in Vercel. It detects SvelteKit and needs no settings
(`adapter-static`, output `build/`).

## The photo pipeline (`pipeline/`, run locally on a Mac)

The source photos sit in the folder above this repo. Bob's captions were typed onto the
photos with Apple Photos' Markup and flattened on export, so they are part of the image
pixels, not metadata. The pipeline reads them and erases them:

| Step | What it does |
|------|--------------|
| `1_find_sources.py` | Lists unique photos (many files are exact copies) → `work/sources.json` |
| `ocr.swift` | Reads text lines + boxes with macOS Vision → `work/ocr.json` |
| `2_clean.py` | Finds caption lines (near-pure white/black typed text), erases them with LaMa inpainting → `work/clean/`, `work/captions.json`, review sheets in `work/masks/` |
| `3_enhance.py` | Repairs scratches/dust (LaMa), sharpens (Real-ESRGAN x2), restores contrast → `work/enhanced/` |
| `5_tag.py` | Guesses year, family branches and topics from each caption → `src/lib/data/tags.json` |
| `4_export.py` | Trims blank bands, writes web images + `photos.json`; adds captions for new ids only |

```
python3 -m venv .venv && .venv/bin/pip install numpy pillow opencv-python-headless torch torchvision spandrel certifi
.venv/bin/pip install --no-deps simple-lama-inpainting
# models/RealESRGAN_x2plus.pth from github.com/xinntao/Real-ESRGAN releases (LaMa downloads itself)
cd pipeline
python3 1_find_sources.py
swiftc -O ocr.swift -o work/ocr && tr '\n' '\0' < work/paths.txt | xargs -0 ./work/ocr work/ocr.json
SSL_CERT_FILE=$(../.venv/bin/python -m certifi) ../.venv/bin/python 2_clean.py
../.venv/bin/python 3_enhance.py
../.venv/bin/python 4_export.py
```

(`work/paths.txt` is the list of paths from `sources.json`, one per line.)

Face restoration (GFPGAN) was tried for "enhance" and rejected: it replaces old,
blurry faces with an invented, modern-looking person.

If the un-captioned originals are still in Bob's Apple Photos library (Markup edits can
be reverted there), exporting those would give perfect clean images. Put them in
`work/clean/<id>.jpg` and skip `2_clean.py`.
